# schematypes

These manually maintained TypeScript types follow the JSON schemas of the
normative revision recorded in
[../normative-contract.json](../normative-contract.json) (private
`avatar_ext_normative` 314c95c5, published as public
[`Kjakubzak/glTF@7ab5368a`](https://github.com/Kjakubzak/glTF/tree/7ab5368a87d1d303dff33ec5f9aad42752e84c78/extensions/2.0/Khronos)
for [KhronosGroup/glTF#2512](https://github.com/KhronosGroup/glTF/pull/2512)
and checked out in [../specification/glTF](../specification/glTF)). They
describe the extension structures used by the converter and viewer and are
not a replacement for JSON Schema validation.
